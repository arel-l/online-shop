# Система управления заказами интернет-магазина
## Описание проекта
Проект представляет собой систему управления пользователями и заказами интернет-магазина.
Программа разработана на языке Java с использованием Spring Boot и Maven.
В дальнейшем система будет расширена для работы с товарами, заказами, оплатой, скидками и возвратами.

## Основные возможности
На текущем этапе реализованы:
работа с пользователями системы;
разделение пользователей по ролям;
администратор;
менеджер заказов;
клиент интернет-магазина;
поиск пользователя по электронной почте;
фильтрация пользователей по роли;
сортировка пользователей по имени;
добавление пользователей;
удаление пользователей;
подсчёт статистики по ролям;
многопоточная обработка пользователей.


## Основные классы
Пакет model
User — абстрактный базовый класс пользователя.
AdminUser — администратор системы.
ManagerUser — менеджер заказов.
CustomerUser — клиент интернет-магазина.
UserRole — перечисление ролей пользователей.
Пакет service
UserService — интерфейс для операций с пользователями.
UserServiceImpl — реализация операций поиска, фильтрации, добавления, удаления и статистики.
UserProcessingService — интерфейс многопоточной обработки пользователей.
UserProcessingServiceImpl — реализация многопоточной обработки пользователей.
Основной класс
KursovayaApplication — точка входа и запуск приложения.
Тесты
KursovayaApplicationTests — проверка запуска Spring Boot-приложения.
UserTest — модульное тестирование классов пользователей.
